<a id="3"></a>
# 3. Perché iniziare con Turtle

[🔙 Torna all'indice](#indice)

---

Molti studenti rinunciano alla programmazione perché i primi programmi sembrano troppo astratti.

Python Creative Lab utilizza un approccio diverso.
Attraverso Turtle ogni istruzione produce un effetto visibile.

Ad esempio:

```python
forward(100)
```
significa: *"Fai avanzare la tartaruga di 100 passi"*.

Una semplice istruzione diventa:
* una linea;
* una figura;
* un disegno;
* un progetto.

Questo permette di comprendere i concetti fondamentali della programmazione in modo naturale.

Durante il corso imparerai gradualmente:
* variabili;
* condizioni;
* cicli;
* funzioni;
* organizzazione del codice.

Ma ogni nuovo concetto sarà sempre collegato a qualcosa di concreto.

# 6. Dal primo comando al tuo mondo digitale

[🔙 Torna all'indice](#indice)

---

Il percorso parte da un elemento semplice:
una linea.
Poi quella linea diventa una forma.
La forma diventa un oggetto.
Gli oggetti costruiscono un ambiente.
L'ambiente diventa un mondo digitale.

Esempio di crescita:
**Linea ➔ Quadrato ➔ Casa ➔ Villaggio ➔ Paesaggio ➔ Animazione**

Ogni risultato nasce dalla combinazione di piccoli programmi.
Questa è una delle idee più importanti della programmazione:
**I grandi progetti nascono dall'unione di piccoli elementi.**
