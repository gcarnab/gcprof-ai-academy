# Q1

# Q3
Che cosa caratterizza la modalità di trasmissione half-duplex?
- [ ] A) I dati viaggiano in una sola direzione, sempre dallo stesso mittente allo stesso destinatario.
- [ ] B) I dati viaggiano in entrambe le direzioni contemporaneamente.
- [x] C) I dati viaggiano in entrambe le direzioni, ma non contemporaneamente: mentre uno trasmette, l'altro riceve.
- [ ] D) Non è possibile alcuno scambio di dati tra i due dispositivi.

- [ ] A) Per aumentare il costo di produzione del cavo.

# Q7

- [ ] C) Perché la velocità delle linee si misura sempre in Megabyte al secondo, non in Megabit.
- [ ] D) Perché il file deve prima essere convertito da bit a byte dal ricevente.
