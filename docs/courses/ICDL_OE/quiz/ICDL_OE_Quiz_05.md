# Q1
Che cosa si intende, correttamente, per modello client-server?
- [ ] A) Un'architettura in cui tutti i dispositivi hanno lo stesso ruolo e condividono direttamente le risorse.
- [x] B) Un'architettura in cui un dispositivo (client) richiede un servizio e un altro dispositivo (server) lo fornisce, rispondendo alla richiesta.
- [ ] C) Un protocollo usato esclusivamente per l'invio della posta elettronica.
- [ ] D) Un tipo di cavo utilizzato per collegare due computer direttamente tra loro.

# Q2
Qual è la principale differenza tra il modello client-server e il modello Peer-to-Peer (P2P)?
- [ ] A) Nel P2P esiste sempre un server centrale a cui tutti i peer si collegano.
- [x] B) Nel P2P ogni dispositivo (peer) può funzionare sia da client sia da server, senza un server centrale.
- [ ] C) Il modello client-server non può essere usato per i siti web.
- [ ] D) Non c'è alcuna differenza: sono due nomi diversi per lo stesso modello.

# Q3

- [ ] C) Il nome commerciale di una connessione Internet.
- [ ] D) Un tipo di cavo usato esclusivamente per le reti in fibra ottica.

# Q5

- [ ] C) Il TCP si usa solo per le e-mail, l'UDP si usa solo per il Web.
- [ ] D) Non c'è alcuna differenza pratica tra i due protocolli.
