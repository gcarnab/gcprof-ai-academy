# Q2
Qual è la differenza corretta tra "tag" ed "elemento" in HTML?
- [ ] A) Sono due termini che indicano cose completamente diverse e mai intercambiabili.
- [x] B) Il tag è il singolo marcatore di apertura o chiusura, l'elemento è l'insieme completo di apertura, contenuto e chiusura.
- [ ] C) L'elemento è solo il tag di apertura, il tag è solo il contenuto.
- [ ] D) Non esiste alcuna differenza tra tag ed elemento.

# Q5
Quale dei seguenti tag è un Void Element, cioè un tag privo di chiusura e di contenuto testuale?
- [ ] A) `<p>`
- [ ] B) `<strong>`
- [x] C) `<br>`
- [ ] D) `<h1>`

# Q6
Osserva questo codice: `<p><strong>Testo</p></strong>`. Perché è scorretto?
- [ ] A) Perché `<strong>` non può mai essere usato dentro un `<p>`.
- [ ] B) Perché manca il tag di apertura di `<p>`.
- [x] C) Perché l'ultimo tag aperto (`<strong>`) non è il primo a essere chiuso, violando la corretta nidificazione.
- [ ] D) Perché `<p>` è un Void Element e non può contenere altri tag.

# Q7
Qual è la regola corretta sulla gerarchia dei titoli HTML in una pagina?
- [ ] A) Si può usare più di un `<h1>` per pagina, purché abbiano contenuti diversi.
- [ ] B) I livelli di titolo possono essere usati in qualsiasi ordine, senza alcuna conseguenza.
- [x] C) Una pagina dovrebbe avere un solo `<h1>`, e i livelli successivi vanno usati in ordine, senza saltarli.
- [ ] D) `<h6>` rappresenta il titolo più importante della pagina.

# Q8
Qual è la differenza corretta tra `<strong>` ed `<em>`?
- [ ] A) `<strong>` serve solo per ottenere il grassetto, `<em>` solo per ottenere il corsivo, senza alcun significato semantico.
- [x] B) `<strong>` comunica importanza semantica, `<em>` comunica enfasi: gli effetti grafici (grassetto, corsivo) sono solo una conseguenza predefinita del browser.
- [ ] C) `<strong>` ed `<em>` sono due nomi diversi per lo stesso identico tag.
- [ ] D) `<strong>` va usato solo nei titoli, `<em>` solo nei paragrafi.
