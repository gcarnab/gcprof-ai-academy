## 📖 MODULO 1 — Fondamenta del Web
*(Contenuto integrale — incluso gratuitamente in questa preview)*

### 1.1 Che cos'è il Web

Quando utilizziamo un browser per visitare un sito Internet, inviare un messaggio o guardare un video stiamo utilizzando una delle più grandi infrastrutture informatiche mai realizzate: il **World Wide Web**, comunemente chiamato semplicemente **Web**.

Il Web è un sistema di documenti collegati tra loro mediante collegamenti ipertestuali (hyperlink) e accessibili attraverso Internet.

È importante distinguere due concetti spesso confusi:

| Termine | Significato |
| --- | --- |
| Internet | Rete mondiale di computer collegati tra loro |
| World Wide Web | Servizio che permette la consultazione di pagine ipertestuali |

Internet rappresenta l'infrastruttura di comunicazione. Il Web è uno dei servizi che utilizzano tale infrastruttura.

### 1.2 Una semplice analogia

Possiamo immaginare Internet come una gigantesca rete autostradale. Le automobili che percorrono le strade rappresentano i dati. Le città rappresentano i server. Le abitazioni rappresentano gli utenti. Il Web è il sistema che permette alle automobili di trasportare documenti da una città all'altra.

### 1.3 Breve storia del Web

Nel 1989 il ricercatore britannico **Tim Berners-Lee**, che lavorava presso il CERN di Ginevra, propose un sistema per condividere documenti scientifici attraverso Internet. Nel 1991 pubblicò il primo sito Web della storia. Da quel momento il Web ha conosciuto uno sviluppo straordinario: oggi miliardi di pagine vengono consultate quotidianamente.

### 1.4 Le tre tecnologie fondamentali

Ogni sito Web moderno nasce dalla collaborazione di tre tecnologie principali:

| Tecnologia | Compito |
| --- | --- |
| HTML | Definisce la struttura della pagina |
| CSS | Definisce la grafica della pagina |
| JavaScript | Definisce il comportamento dinamico |

Questo corso è interamente dedicato ai primi due linguaggi: **HTML** e **CSS**.

### 1.5 Una metafora molto utile

Immaginiamo di costruire una casa:

| Parte della casa | Tecnologia |
| --- | --- |
| Muri e fondamenta | HTML |
| Pittura, mobili e arredamento | CSS |
| Impianto elettrico e automazioni | JavaScript |

HTML costruisce. CSS abbellisce. JavaScript rende la pagina intelligente.

### 1.6 HTML e CSS non sono linguaggi di programmazione

Uno degli errori più frequenti è considerare HTML un linguaggio di programmazione. In realtà è un **linguaggio di marcatura**: descrive il contenuto di una pagina (titoli, paragrafi, immagini, link, tabelle, moduli), ma non possiede variabili, cicli, funzioni o condizioni.

Anche CSS è un linguaggio **dichiarativo**: descrive come gli elementi HTML devono essere visualizzati (colori, caratteri, dimensioni, sfondi, bordi, animazioni, layout, responsive design).

### 1.7 Perché studiare ancora oggi HTML e CSS

Anche framework moderni come React, Angular, Vue e Next.js generano comunque codice HTML e CSS "sotto il cofano". Per questo comprenderne davvero il funzionamento è il prerequisito indispensabile prima di affrontare qualsiasi tecnologia più avanzata.

### Client e Server: come "arriva" davvero una pagina Web

Quando apriamo una pagina Web entrano in gioco due computer: il **Client** (il tuo browser) e il **Server** (il computer che ospita il sito). Il Client richiede una pagina, il Server la invia.

```
+-----------------+
|     CLIENT      |
| (Browser Web)   |
+-----------------+
         |
         | Richiesta HTTP
         V
+-----------------+
|     SERVER      |
|  Web Server     |
+-----------------+
         |
         | Risposta HTTP
         V
+-----------------+
|     CLIENT      |
| Visualizza HTML |
+-----------------+
```

Ogni pagina Web possiede un indirizzo chiamato **URL**. Analizziamone uno:

```
https://www.gcprof-academy.com/corsi/html/index.html
```

| Parte | Significato |
| --- | --- |
| https | protocollo |
| www.gcprof-academy.com | dominio |
| corsi | cartella |
| html | sottocartella |
| index.html | pagina |

## ✅ Best Practice (anteprima)

✔ Imparare prima HTML, poi CSS, solo dopo JavaScript.

✔ Non affidarsi a strumenti visuali (drag & drop) prima di conoscere il codice.

✔ Riscrivere personalmente ogni esempio, mai solo leggerlo.

## ❌ Errori comuni (anteprima)

❌ Pensare che HTML sia un linguaggio di programmazione.

❌ Pensare che CSS serva soltanto a cambiare i colori.

❌ Copiare codice senza comprenderlo davvero.
