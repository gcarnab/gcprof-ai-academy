# Q1
Quale delle seguenti definizioni descrive correttamente un algoritmo?
- [ ] A) Un linguaggio di programmazione utilizzato per scrivere software.
- [x] B) Una sequenza ordinata, finita e non ambigua di istruzioni che permette di risolvere un problema.
- [ ] C) Un software che traduce automaticamente lo pseudocodice in Python.
- [ ] D) Un insieme di dati di input necessari per risolvere un problema.

# Q2
Qual è la relazione corretta tra problema, algoritmo e programma?
- [ ] A) Sono tre termini equivalenti, intercambiabili in qualsiasi contesto.
- [ ] B) Il programma viene scritto prima dell'algoritmo, che serve solo a documentarlo.
- [x] C) Il problema è la situazione da risolvere, l'algoritmo è la procedura risolutiva, il programma è la traduzione dell'algoritmo in un linguaggio di programmazione.
- [ ] D) L'algoritmo è una traduzione del programma in linguaggio naturale.

# Q3
L'istruzione "Conta per sempre" non può essere considerata un algoritmo valido. Quale caratteristica viola?
- [ ] A) L'ordine.
- [x] B) La finitezza: un algoritmo deve terminare dopo un numero limitato di operazioni.
- [ ] C) L'efficacia.
- [ ] D) La produzione di un risultato.

# Q4
L'istruzione "Aggiungi un po' di zucchero" è considerata scorretta in un algoritmo. Per quale motivo?
- [ ] A) Perché contiene un errore di ortografia.
- [ ] B) Perché non rispetta l'ordine delle operazioni.
- [x] C) Perché è ambigua: "un po'" non rappresenta una quantità precisa e misurabile.
- [ ] D) Perché è un'istruzione troppo breve.

# Q5
Perché l'istruzione "Indovina il numero pensato da una persona" non può essere considerata un algoritmo?
- [ ] A) Perché è troppo lunga da eseguire.
- [ ] B) Perché non produce mai un risultato.
- [x] C) Perché non esiste una procedura eseguibile che garantisca di ottenere quel risultato: viola la caratteristica di efficacia.
- [ ] D) Perché non è scritta in pseudocodice.

# Q6
Osserva questo semplice algoritmo:
```
Leggi numero
quadrato = numero × numero
Visualizza quadrato
```
Quale caratteristica fondamentale delle istruzioni elementari viene rispettata?
- [ ] A) Ogni riga rappresenta più azioni contemporanee.
- [x] B) Ogni riga rappresenta un'unica azione precisa: leggere, calcolare, visualizzare.
- [ ] C) L'ordine delle istruzioni può essere invertito senza alcuna conseguenza.
- [ ] D) Le istruzioni non necessitano di essere eseguibili.

# Q7
Uno stesso algoritmo può essere tradotto in Python, in Java o descritto a parole a un'altra persona, ottenendo sempre lo stesso risultato logico. Cosa dimostra questo fatto?
- [ ] A) Che l'algoritmo dipende sempre dal linguaggio di programmazione scelto.
- [x] B) Che è l'algoritmo, e non il linguaggio, a contenere davvero la soluzione del problema.
- [ ] C) Che un algoritmo può essere eseguito solo da un computer.
- [ ] D) Che non è possibile tradurre un algoritmo in più linguaggi diversi.
