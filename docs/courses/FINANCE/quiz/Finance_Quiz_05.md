# Q6
Cosa significa la lettera "A" nell'acronimo SMART, applicato a un obiettivo finanziario?
- [ ] A) Automatico: l'obiettivo si raggiunge senza bisogno di alcuna azione concreta.
- [x] B) Accessibile: l'obiettivo deve essere realisticamente raggiungibile con le proprie risorse.
- [ ] C) Astratto: l'obiettivo non deve avere una cifra o una scadenza precisa.
- [ ] D) Ambizioso: l'obiettivo deve essere il più alto possibile, senza limiti.

- [ ] C) Il fattore tempo non ha alcuna influenza sulla scelta degli strumenti più adatti.
- [ ] D) È sempre preferibile un unico strumento ad altissimo rischio, per massimizzare il risultato finale.
