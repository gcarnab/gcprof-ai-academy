<a id="convenzione-navigazione"></a>
## 🧭 Convenzione di navigazione per i file dei moduli

Per garantire coerenza e navigabilità tra tutti i file del corso, ogni file di modulo (es. `Finance_01_Modulo_1.md`) dovrà seguire questa struttura:

1. **Titolo del modulo** (H1)
2. **Indice dei capitoli del modulo**, con ancore interne (`<a id="capitolo-1"></a>`, ecc.)
3. **Contenuto dei singoli capitoli**, in ordine, ciascuno con un link `[⬆ Torna all'indice del modulo](#indice-modulo)` al termine
4. **Al termine dell'intero file**, un link finale che riporta all'indice dei capitoli del modulo stesso (non all'indice generale del corso)

Esempio di intestazione tipo per ogni futuro file di modulo:

```markdown
# Modulo 1 — Fondamenta dell'Educazione Finanziaria

<a id="indice-modulo"></a>
## Indice del modulo
1. [Cos'è l'Educazione Finanziaria](#capitolo-1)
2. [Il valore del denaro nel tempo](#capitolo-2)
3. [Psicologia della finanza e decisioni consapevoli](#capitolo-3)

---
```
